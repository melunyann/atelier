melune ポートフォリオ

ふつうのWebサイトとして、レンタルサーバーや無料ホスティングに置けるファイル一式です。ビルドやインストールは要りません。

1. まず自分のパソコンで確認する

下のボタンを押すか、フォルダの中のファイルをダブルクリックして開きます。Chrome・Edge・Safariなどの、ふつうのブラウザで開けます。

公開サイトを見る編集ツールを開く

最初は画像が入っていないので、淡い色の空のフレームが表示されます。編集ツールで画像と文字を入れると完成します。

2. フォルダの中身

melune-portfolio/
├─ START-HERE.html        この説明
├─ site/                  ★ 公開するのはこのフォルダだけ
│   ├─ index.html         トップページ
│   ├─ favicon.svg        ブラウザのタブに出る小さなアイコン
│   ├─ assets/            デザイン（style.css）と表示の仕組み（site.js）
│   ├─ data/site.js       文字・設定・作品の並び（編集ツールが自動で書き出します）
│   └─ images/            作品の画像など
└─ editor/                ✕ 自分のパソコン専用。アップロードしないでください
    ├─ index.html         編集ツール
    ├─ editor.css
    └─ editor.js

3. 作品を入れて、更新する流れ

  1. editor/index.html を開きます。
  2. 「プロフィール」でメイン画像・アイコン・紹介文を、「作品」で作品画像・タイトル・説明・カテゴリーを入れます。「文字」「デザイン」では見出しやボタンの文字、フォント、太さ、斜体、色を変えられます。
  3. 入力内容は、自動で下書きとして保存されます。ブラウザを閉じても残ります。
  4. 右上の「プレビュー」で、PC表示とスマホ表示を確認します。
  5. よければ「サイトに反映」を押します。更新用のZIPファイルが保存されます。
  6. ZIPを解凍して、中の data フォルダと images フォルダを、site フォルダに上書きコピーします。
  7. site フォルダの中身を、ホスティングにアップロードします（4.を参照）。
編集ツールの「サイトに反映」は、ZIPを作るところまでです。ファイルを site フォルダに入れてアップロードするまで、公開ページは変わりません。下書きの途中の内容が、勝手に公開されることはありません。

4. インターネットに公開する

site フォルダの中身（index.html、assets、data、images、favicon.svg）を、ホスティングのいちばん上の場所にアップロードします。トップページは index.html として表示されます。

方法向いている人やること
Netlify などの静的サイト向けサービス手軽に始めたいsite フォルダを、サービスの画面にドラッグ＆ドロップします。
Cloudflare Pages / GitHub Pages無料で長く使いたい画面の案内に沿って site の中身を登録します。
レンタルサーバー（FTP）すでに契約しているFTPソフトで、公開用フォルダ（多くは public_html）に site の中身を入れます。

各サービスの画面や手順は変わることがあります。アップロードの方法は、使うサービスの公式案内で確認してください。

公開URLは、使うサービスが発行します。独自ドメインを使う場合も、そのサービスの設定画面で行います。

5. 知っておいてほしいこと

「本人だけが編集できる」仕組みについて

公開されるのは site フォルダだけで、編集の画面はそこに入っていません。そのため、訪問者が見る公開ページに編集ボタンは出ませんし、公開ページから内容を書き換えることもできません。編集は、自分のパソコンにある editor でだけ行います。ログインの仕組みはありません。editor フォルダをアップロードしないことが、本人専用を守る方法です。

下書きの保存場所

下書きと、まだ書き出していない画像は、使っているパソコンのブラウザの中に保存されます。ブラウザのサイトデータを消したり、別のパソコンやブラウザで開いたりすると、下書きは見えません。大事な内容は「サイトに反映」でZIPを書き出し、site フォルダごとバックアップしておいてください。別のパソコンで続きをする場合は、melune-portfolio フォルダごとコピーします。

画像について

画像は、縦横比を保ったまま長辺2000px（メイン画像は2560px）までに整えて、site/images に保存されます。切り抜きや枠線は付きません。画像が外部のAIサービスなどに送られることはありません。編集ツールが外につなぐのは、フォントを読み込むためのGoogle Fontsだけです。

images フォルダの中のファイル名は変えないでください。使わなくなった画像のファイルは、手で削除して構いません。

フォント

フォントはGoogle Fontsから読み込むため、インターネットにつながっていないと、代わりのフォントで表示されます。

うまくいかないとき

  • 画像が表示されない： site/images に、書き出したZIPの images の中身を入れ忘れていないか確認してください。
  • 文字や並びが変わらない： ZIPの data/site.js を site/data に上書きしたか、ブラウザを再読み込みしたか確認してください。
  • 編集ツールに下書きが出ない： 別のブラウザで開いていないか確認してください。
